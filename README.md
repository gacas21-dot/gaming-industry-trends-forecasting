# gaming-industry-trends-forecasting
Análisis predictivo del mercado global de videojuegos para la tienda Ice. Identifiqué patrones de éxito (2013-2016) mediante EDA y pruebas de hipótesis, evaluando el ciclo de vida de consolas y la correlación entre reseñas y ventas regionales. Generé insights estratégicos para la planificación de campañas comerciales y gestión de inventario
